# 경기 규칙과 포제션

## 기본값

| 규칙 | 기본값 |
|---|---:|
| 코트 | 15×14m 하프코트 |
| 골대 | (7.5, 1.2)m |
| 아크 | 반경 6.75m |
| 공격 제한시간 | 12초 |
| 최대 드리블 행동 | 3회 |
| 아크 안 / 밖 득점 | 1 / 2점 |
| 승리 점수 / 필요한 점수차 | 11 / 1 |
| 득점 상한 / 포제션 상한 | 21 / 300 |
| 공격 리바운드 시계 최소값 | 6초 |
| 자유투 적용 누적 파울 단위 | 4회 |
| 기본 적분 틱 | 0.1초 |
| 예약 최대 길이 | 6행동 |

설정의 유한성·범위·정수 조건을 검증한다. 경기 종료는 목표점수와 필요한 점수차, 최대점수 또는 최대포제션으로 판정한다. 포제션 상한에서 동점이면 무승부다. 종료 후 새 명령은 거부한다.

## 체크볼 및 역할 변경

득점, 수비 리바운드, 정상적인 탈취/공격자 턴오버/공격시간 위반은 새 공격자의 체크볼로 이어진다. 선수는 p1/p2 정체성을 유지하며 역할만 바뀐다. 점수와 누적 피로/파울은 유지하고, 위치·속도·드리블·개더·공 제어·행동 상태를 새 포제션에 맞게 초기화한다. 큐는 지워진다.

공격 리바운드와 원공격자의 루즈볼 회수는 같은 포제션이다. 남은 드리블 횟수를 되살리지 않는다. 회수는 공을 잡은 상태로 처리하므로 이후 풋워크·슛을 선택한다.

## 드리블 및 풋워크

3회는 공식 규정이 아닌 본 게임의 행동 단위 제한이다. 기술별 드리블뿐 아니라 라이브 드리블을 계속하면서 시작하는 Walk/Sprint도 1단위를 사용해 이동 명령으로 제한을 우회하지 못하게 한다. 진행 중인 행동의 ContinueAction은 중복 비용을 내지 않는다.

초기 정지 상태에서 공을 들고 Walk/Sprint를 시작할 수 없다. 먼저 드리블한다. 개더 뒤 허용되는 발걸음은 최대 두 스텝이며 공을 든 채 Sprint는 불가하다. 피벗·잽·페이크·볼 보호는 고정 발과 드리블 종료 상태를 적용한다. 남은 예산이 있더라도 ended에서 재드리블은 더블 드리블이다.

명백히 불법인 명령은 제출 단계에서 거부하며 이때 공격권을 빼앗거나 시계를 진행하지 않는다. 실행 중 발생하는 아웃오브바운즈·시간초과·탈취 등은 실제 턴오버다. 사용자가 오류 버튼을 눌렀다는 이유만으로 경기 결과를 바꾸지 않는다.

## 시간과 중간 의사결정

기본 틱은 설정 가능한 최대 적분 간격이다. 인터럽트/릴리스/행동 종료가 틱 사이에 있으면 그 경계에서 더 작은 하위 간격으로 적분한다. 양측은 항상 같은 dt를 사용한다. 동작 시작/제어/슈팅 준비/완료 및 공 상태 변화에서 결정점을 연다.

짧은 행동이 끝났다고 상대의 긴 행동을 버리지 않는다. 진행 중 runtime을 유지하고 ContinueAction으로 이어간다. 교체 가능한 인터럽트 창에서만 새 행동으로 바꿀 수 있고, 이미 시작한 드리블 비용은 취소해도 되돌리지 않는다.

## 파울 정책

- 비슈팅 수비 파울: 같은 포제션. 드리블/종료 상태 유지, 시계를 최소 min(6,설정 슛클록)까지 복원하고 수비 간격을 재설정한다.
- 수비 파울 누적이 foulLimit의 배수: 자유투 1회 후 소유권 전환
- 슈팅 파울: 실패한 안쪽/바깥쪽 슛은 각각 자유투 1/2회, 성공한 슛은 득점 인정 후 추가 1회
- 자유투는 1점. 확률 = clamp(0.32+0.0042CloseShot+0.002Composure−0.0012fatigue,0.15,0.96)
- 차징 조건: 빠른 공격자가 자리 잡은 수비 경로에 강하게 진입한 경우 공격자 파울과 턴오버

파울/자유투는 이 1:1 게임의 명시적 단순화이며 공식 리그 전체 규칙과 동일하지 않다.
