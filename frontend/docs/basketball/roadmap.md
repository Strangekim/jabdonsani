# 범위와 후속 확장

## 이번 범위

브라우저 로컬 1:1 하프코트, 순수 TypeScript 엔진, 동시 비공개 명령, 3 드리블 행동 제한, 양방향 조작, AI, 리플레이, 자동 테스트와 통계. 구현 및 검증 사실은 `test_results.md`에 기록한다.

## 이번 범위가 아닌 기능

- 온라인 매칭, 계정, 결제, 서버 권위 PvP
- 실제 NBA 데이터 피팅 및 프로 선수 라이선스
- 실사 3D, Unity/Unreal 연동, 강체 물리
- 네트워크 부정행위 방지 또는 브라우저 개발자 도구에 대한 로컬 비밀 보장

## 가능한 다음 작업

1. 실제 플레이어 피드백과 통계로 수식/AI 정책 보정. 변경 전후 동일 시드 묶음과 지표를 저장한다.
2. 서버가 GameState/난수/제출을 보유하고 각 클라이언트에는 PlayerObservation만 전송한다. 인증된 playerId, decisionId, 중복/지연 제출, 타임아웃 및 재연결 정책을 추가한다.
3. 필요하면 온라인 commit/reveal 프로토콜을 추가한다. 현재 hotseat 가림 화면은 암호학적 보안 장치가 아니다.
4. GameEvent의 시간·좌표·행동·데이터를 3D 애니메이션 어댑터에 매핑한다. 렌더러가 판정을 변경하지 않게 한다.
5. 실측 선호에 따라 코트·선수 신체 치수, 더욱 정교한 피벗/점프 착지, 리바운드 궤적 및 접촉 모델을 확장한다.

후속 기능의 기반은 단일 상태와 순수 명령 전이 API다. 미래 확장을 위해 현재 사용하지 않는 장식용 스탯이나 더미 서버를 추가하지 않는다.
