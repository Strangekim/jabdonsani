# 좌표·이동·공간 상호작용

## 코트

기본 코트는 가로 15m, 세로 14m, 골대 (7.5, 1.2), 아크 반경 6.75m다. x는 오른쪽, y는 골대에서 멀어지는 화면 아래쪽이다. 체크볼은 골대에서 약 7.2m 떨어진 중앙에서 시작하며 수비는 1.65m 앞이다. 좌표는 설정에 맞게 경계 안에서 관리한다.

## 공통 이동 계산

공격과 수비의 속도 적분은 `proposedMove` 하나를 사용한다.

1. 명령 방향 또는 행동별 기본 목적지를 정규화한다.
2. Speed·피로·현재 균형·행동 이동배율로 최고속도를 계산한다. 수비 횡이동과 드리블은 해당 능력 배율을 추가한다.
3. 사용자가 지정한 속도 비율(0~1)을 곱한다.
4. 방향전환 turn=(1−기존속도방향·새방향)/2와 Agility로 급회전 속도를 감쇠한다.
5. 목표속도보다 느리면 가속 (2+0.075Acceleration)×F, 빠르거나 반대 방향이면 감속 (2.8+0.085Deceleration)×F를 적용한다.
6. Δv를 가감속×dt 이내로 제한한 뒤 위치 += 새속도×dt로 적분한다.
7. 틱 구간의 상대 이동 선분을 검사하여 빠른 이동이 수비를 관통하지 않게 하고, 양측 제안 위치로 경로 선점·접촉·경계를 해석한다. 한 선수를 먼저 움직이고 그 결과에 다른 선수를 맞추지 않는다.

수비 반응 지연 중에는 목표속도 0을 적용하므로 순간 방향 변경이 불가능하다. 기존 관성과 감속은 여전히 계산한다. 한 행동이 끝나면 다음 결정점까지 무료 추가 행동을 하지 않는다.

## 행동별 차이

Hesitation은 초기 40% 진행에서 속도를 낮추고 SpinMove는 초기 30%를 느리게 시작한다. 슛은 후반 릴리스 구간에 속도를 줄인다. RetreatDribble/StepBack/StepBackShot은 기본 후퇴, SideStep은 측면, 수비 슬라이드는 좌우, CloseOut은 공격자 접근이다.

HoldPosition/CutOffDrivingLane은 공격자에서 골대 쪽의 원하는 간격으로 이동한다. ShadeLeft/Right는 경로 옆을 점유한다. AnticipateDirection은 지정 방향으로 선점 목적지를 조절한다. 사용자가 직접 방향을 지정하면 해당 입력을 우선한다.

## 풋워크와 경계

피벗·잽·볼 보호·페이크·개더의 고정 발은 관성 이동으로 규칙을 우회할 수 없게 한다. 개더 스텝은 Footwork 기반 최대 이동거리로 제한한다. 공을 든 채 이동할 수 있는지는 공간 계산 전에 드리블/개더 규칙으로 검증한다.

이벤트 턴의 돌파 경합은 입력 방향, 수비 예측, 공수 능력치·자원, 이전 턴의 우위를 함께 평가한다. 저지 확률에 시드 난수를 적용한 뒤 돌파·강제 공 잡기·루즈볼 등의 결과와 다음 위치를 확정한다. 좌우 입력은 해당 쪽에서 골대로 향하는 경로, 후퇴 입력은 골대에서 멀어지는 경로로 해석한다. `attribute_formulas.md`의 이벤트 턴 돌파 판정을 참조한다.

성공한 돌파의 우위와 수비 지연은 다음 턴에 남으며, 수비가 추격하거나 후퇴해 복귀할 수 있다. 공간 우위가 생겼다고 즉시 득점이나 공격권 전환을 보장하지 않는다. 이 위치 갱신은 완결된 플레이를 표현하는 논리 모델이며 정밀 강체 물리 재현은 아니다.

## 적분 세부 수식

민첩 계수 G=(0.45+0.0055Agility)×F이고 목표속도에(1−turn×(1−0.75G))를 곱한다. 속도차 Δv에 min(1,가감속×dt/max(0.0001,|Δv|))를 곱해 새속도를 만든다. 회복 지연 동안에는 동작을 새로 시작하지 않는다.

접촉 구간 검사는 상대 시작벡터 r0, 종료벡터 r1, Δr=r1−r0에서 t=clamp(−r0·Δr/max(1e−9,Δr·Δr))를 구하고 |r0+tΔr|로 최소 간격을 평가한다. 구간에서만 접촉해도 가까운 시점으로 이동을 제한한 뒤 겹침을 해소한다.

일반 개더 풋워크의 행동당 거리 상한은0.55+0.006Footwork m, 러닝 마무리는0.7+0.004Footwork m다. 강체/관절 물리 대신 명시적인 발걸음·경로 모델이다.

## 이벤트 턴의 도달 가능성

공격의 좌우 돌파 경로는 내부 적분과 최종 판정이 같은 방향을 사용한다. 속도 0에서 정지한 선수는 앞으로 재배치되지 않으며, 기존 관성은 감속 공식대로 줄어든다. 기술별 이동 배율을 적용한 실제 도착점을 보존한다. 드리블 단위의 실행 시간은 기본 행동 시간의1.3배이며, 수비 이동은 돌파 상호작용 전체에 걸쳐 진행한다.

수비의 최종 보정은 이전 위치에서 속도·행동 시간·반응 및 회복 지연으로 도달 가능한 거리 안으로 제한한다. 후퇴 드리블은 수비를 공격자 앞으로 강제 이동시키지 않는다. 뒤처진 수비의 RetreatStep은 림 복귀를 위한 달리기 배율을 쓰며 실제 도달 가능한 경우에만 다시 경로를 막을 수 있다.
