# 밸런스 및 통계 보고서

## 실행 표본

기본 올라운더(30개 능력치 각65), normal AI, 시드20261013, 기본11점 선승. 최소10,000포제션과100경기를 모두 넘길 때까지 **경기를 끝까지** 실행했다. 마지막 경기의 나머지 포제션도 포함하므로 정확히10,000에서 자르지 않는다. 현실 선수 데이터에 대한 적합성 검증이 아닌 현재 엔진/정책의 계측이다.

## 수정 전후 비교

같은 설정·초기 시드 묶음이다. 정확한 인터럽트, 진행 보존, 난수 초기 혼합, 이동 경로 검사를 보강하면서 난수 소비 경로와 전략 시점이 바뀌었다. 따라서 동일 경기의 인과효과 실험 또는 슛 능력치 임의 조정의 결과라고 해석하지 않는다. 일반 슛/체력 수식의 계수는 이 비교 과정에서 편의상 바꾸지 않았다.

## 분포 해석 및 경고

- 기본표본에서 P1은 매 경기 선공이며 177/303승 (58.42%). Wilson 95%구간은 52.8–63.8%다. 50%와 차이가 있어 선공 이점이 의심된다. 선수 ID 자체의 임의 보너스를 뜻하지는 않으며, 같은 시드에서 선공을 바꾼 별도 실험과 역할 교환 회귀 검사를 사용한다.
- 인터럽트 후 실제 결정점이 늘어 포제션당 약28회다. 즉시 한 행동 전체를 마치는 초기 버전과 결정점 수를 같게 만들려고 기능을 삭제하지 않았다. 실제 인간 플레이의 피로도/자동재생 속도는 추가 사용성 검증 대상이다.
- 돌파 비율은 공간 우위 발생 횟수/적격 이동 행동 수다. 초기 보고서와 최종 보고서의 분모 집계가 달라 백분율끼리 직접 비교하지 않는다. 공간 우위 횟수/포제션은 초기 0.425, 최종 0.109이다.
- 스틸/블록 수비 행동 선택에는 실제 적절한 거리나 슛이 없던 경우도 포함된다. 슛을 실제로 맞닥뜨린 블록 기회만 분모로 하는 공식 스포츠 통계와 다르다.
- 체력 소모는 회복/상한 적용 후 게이지 차이가 아니라 누적 행동 비용이다. 최종 양측 합계 포제션당 23.776 비용 단위다.
- 기술별 성공은 제어 체크 통과를 뜻하며 수비 돌파/득점과 별개다. 사소한 미사용/미관측을 규칙 오류로 취급하지 않지만, 기술 다양성은 후속 밸런스 대상이다.

## 선공 교환 및 추가 실험

동일시드100쌍의 선공 교환은 총200경기다. P1선공55/100승, P2선공56/100승; 합친P1승률49.5%(99/200), 선공승률55.5%(111/200)였다. 선수ID의 우위가 입증된 결과는 아니며 선공 효과/표본변동을 구분해야 한다. 짝지은 표본의 독립성까지 가정한 확정적 유의성 주장은 하지 않는다. 원자료: results/first-possession-symmetry.json.

추가로30개 스탯×2수준×8경기=480경기,5개 프리셋의25조합×4경기=100경기를 실행했다. 스탯별8경기 승률은 작은 표본이고 이후 플레이 경로가 달라지므로 한 능력치의 단조효과 증명이 아니다. 이 표본에서는8개 스탯의 높은값 승률이 낮은값보다 낮게 관측된 경우도 그대로 기록했다.

필수8개 관계는 각수준512개의 동일시드 쌍을 별도로 실행해 확인했다. BallHandling 제어평균61.53→86.89, Steal 실제성공12.30%→39.26%, Endurance 행동비용4.85→3.34 등이며 나머지 수치·조건은 results/controlled-attributes.json을 참조한다.

전체기술×수비7,680회 단일행동 실험은 정면1m의 한정된 시작배치를 사용하므로 모든 셀의 완전돌파가0이어도 보편적인 돌파불가를 의미하지 않는다. 실제 경기표본에서는1,088회 공간우위가 관측됐다. 제어·스틸·전진거리와 돌파를 혼동하지 않는다.

추가 공간배치 검증은5,760회다. 정면 경로0/1,920회와 열린 왼쪽 경로1,224/1,920회(63.75%)의 돌파 차이를 관측했다. 동일 기술도 위치·길에 따라 결과가 달라지는 실행 증거이며 특정 기술의 보편적 성공률을 뜻하지 않는다. 원자료: results/spatial-technique-probes.json.

전체 통계·추가 경기 검증은 합계34,938종료 포제션,1,083완주 경기다(기본303+능력치480+프리셋100+선공교환200). main runner364.57초, 별도 선공감사 약82.58초, 공간검증5.8초. 정확한 합계·분모·표본한계는 results/run-summary.json 및 balance-analysis.json에 기록했다.
