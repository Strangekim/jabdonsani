# 체력, 순간 에너지, 피로와 균형

공격과 수비 모두 동일한 `updateResources` 경로를 사용한다. 포제션이 끝나도 체력·누적 피로는 선수 정체성에 남는다.

## 세 가지 자원

- stamina: 전체 경기 체력, 0~100
- burstEnergy: 가속·점프 등 순간 에너지, 0~100
- fatigue: 누적 피로, 0~100

틱 dt의 행동 비용:

- E = 1.35 − 0.0045Endurance − 0.002주능력 평균
- 체력소모 c = 기본 staminaCost × E × dt / 실제 행동시간
- 순간에너지 소모 = 기본 burstCost × E × dt / 실제 행동시간
- 누적피로 증가 = c × (0.09 − 0.00045Endurance)

행동이 완료됐거나 낮은 강도(staminaCost < 1.2)이면 초당 stamina 0.4+0.008Endurance, burstEnergy 3+0.045Endurance를 회복한다. 회복량과 소모량을 분리해 순소모와 실제 에너지 사용량을 혼동하지 않는다.

체크볼 시 stamina +4, burstEnergy +14를 상한 100까지 회복한다. bodyBalance는 최소 85로 복구하고 공 제어 상태도 새 공격에 맞게 초기화한다. fatigue는 체크볼마다 0으로 초기화하지 않는다.

## 연속 성능 감소

F = (0.58+0.42stamina/100) × (1−0.23fatigue/100) × (0.78+0.22burstEnergy/100)

F는 이동속도·가속/감속·균형 회복·공 제어·수비 경합·슛·점프 계산에 쓰인다. 자원이 특정 값 아래로 내려갔다고 모든 동작을 갑자기 실패시키지 않는다.

## 균형

- 기본 회복/초 = (3+0.07Balance+0.035BodyControl) × F
- RecoverBalance는 회복배율 2.2, 일반 동작은 0.4
- 방향전환 손실 = turn × (8−0.045Balance−0.022Footwork) × dt × 속력
- turn = clamp((1−이전속도방향·목표방향)/2)
- 각 행동의 balanceModifier를 실제 실행시간에 나눠 틱마다 적용

현재 균형은 최고속도·반응 지연·제어·슛·컨테스트·회수에 반영된다. 급격한 방향 전환을 반복하거나 점프 수비를 남발하면 다음 의사결정의 수행 조건이 달라진다.
