# INK v0.4 밸런스 실험

## 범위 및 방법

실험은 68경기, 총 1,944개 행동(강제 오프닝과 패스 포함), 18개 실험 배치다. 현재 3D 표면 메시, 도색, 건설, 점유권 및 실제 턴 엔진을 사용했다. 기본 맵 면적 계수는 4. 각 조건의 AI 행동은 결정론적이며 대부분 빠른 탐색, 일부 일반 2 AP 탐색이다. 후보 비교 중 AI 평가 함수와 엔진 규칙이 달라진 배치가 있으므로 전체 결과를 독립 표본으로 합산해 승률을 추정하지 않는다. 강제 건설 오프닝은 해당 건물에 투자했을 때의 결과를 보는 실험으로 자유 선택 빈도와 구분한다. 전체 기록: [balance-v04-results.json](./balance-v04-results.json).

검토한 조합: 본진 사거리, 무기 도색 반경/예산, 높이 보너스, 상부 과반 조건, 돔/타워/장벽/아치의 크기, 장벽 대신 낮은 단상, 장벽 높이 2.4/2.5/3, 잠복 잉크 반경 확대, 여러 AI 성향과 2/3/4인 경기, 건설자 좌석 교환. 기존 엔진 및 프로토타입 후보를 단계별로 시험했다.

## 채택 설정

| 변수 | v0.3 | v0.4 |
|---|---:|---:|
| 본진 낮은 폭탄 사거리 | 5.5 | 4.3 |
| 본진 높은 폭탄 사거리 | 4.2 | 3.3 |
| 높이당 사거리 보너스 | 1.5 | 1.8 |
| 기본 폭탄 반경 | 1.25 | 1.15 |
| 고지대 반경 보너스 | 0 | 높이 × 0.11, 최대 0.33 |
| 폭탄 잉크 도달 예산 | 5 | 본진 5 / 고지대 5.7 |
| 잉크 건 반경 | 0.56 | 0.65 |
| 잉크 건 잉크 도달 예산 | 9 | 7 |
| 공중 투하 반경 | 0.85 | 0.95 |
| 공중 투하 잉크 도달 예산 | 3 | 3.5 |

고지대 폭탄은 건물의 상부(높이 >= 0.5, 법선 y >= 0.35) 면적 과반을 점유한 플레이어만 자기 색의 상부에서 사용한다. 이는 건설자 전용 권한이 아니라 현재 점유 상태의 함수다. 붓과 잠복 잉크, AP, 표면 면적 점수는 유지한다. 건물은 돔 반지름 1.25, 타워 반지름 0.65/높이 2.5, 장벽 높이 2.4(길이 3/두께 0.5), 아치 기존 규격 유지.

## 최종 후보 검증

2인 8라운드 균형형 빠른 AI. P1은 첫 턴 건설+공중 투하를 지정하고 이후 자율 행동. 기존 설정과 최종 설정의 같은 실험 방법 비교:

| 건물 | 기존 P1/P2 | 기존 P1/P2 고지대 폭탄 | 최종 P1/P2 | 최종 P1/P2 고지대 폭탄 |
|---|---:|---:|---:|---:|
| 돔 | 35.38 / 40.94 | 6 / 8 | 44.75 / 43.42 | 11 / 0 |
| 타워 | 47.20 / 45.86 | 4 / 0 | 48.37 / 41.85 | 12 / 0 |
| 장벽 | 38.49 / 45.64 | 6 / 8 | 49.77 / 43.30 | 10 / 0 |
| 아치 | 40.75 / 45.89 | 6 / 7 | 46.85 / 46.12 | 6 / 0 |

각 행은 한 경기이므로 모든 좌석이나 상황에서 건설이 우월함을 의미하지 않는다. 고지대 보너스를 더 크게 설정한 일반 AI 1:1은 두 플레이어가 각각 타워 1회/공중 투하 1회/고지대 폭탄 13회/붓 1회를 사용했다. 더 약하게 설정한 후보는 양측 모두 건설하지 않았다. 중간 후보는 일반 균형형 AI 1:1에서 한쪽만 타워를 사용했으며 43.18 / 45.19 면적, 고지대 투척 0 / 9회, 총 도색률 63.7%, 상대 잉크에 닿은 도색 20/31회였다.

4인 8라운드 자유 대전(균형/공격/건축/확장): 47.11 / 30.39 / 33.81 / 58.99. 건설 3회(타워 2, 아치 1), 고지대 폭탄 15회, 도색률 58.2%, 교전 도색 35/61회. 건축형이 필승하지 않으며, 확장형 승리. 잠복 잉크 확대 시험은 AI 선택을 회복하지 못해 보류한다. 잉크 건과 잠복 잉크의 활용도, 다인전의 건설 ROI와 선턴 편차는 추가 검증 대상이다.

장벽 3 높이와 단상은 실험에서 과도하거나 배치 의존적이어서 미채택. 타워의 높이를 완화하고 돔 표면을 확대했다. 기존 건물 4종을 유지한다.

## 재실행

프론트엔드에서 `node scripts/ink/balance.mjs`는 짧은 3경기, `node scripts/ink/balance.mjs --full`은 현재 엔진의 장기 자유 대전 및 양 좌석 건설 오프닝 검증을 실행하고 JSON을 출력한다. 역사적 후보 결과는 위 JSON에 보존했다. 과거 임시 엔진을 모두 재현하는 스크립트는 아니다. 규칙 검증: `node --test tests/ink/*.test.mjs`.
