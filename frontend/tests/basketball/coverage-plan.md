# 마이크로 턴 농구 검증 계획

이 문서는 구현 전 사양을 기준으로 정한 검증 범위다. 통과 여부는 실제 실행 결과에 기록한다.

| 사양 | 검증 수단 | 요구되는 증거 |
| --- | --- | --- |
| 2.1 경기 규칙 | 단위·자동 경기 | 체크볼, 12초, 1/2점, 11점 종료, 공격권 전환 |
| 2.2 드리블 상한 | 단위 테스트 10개 이상 | 0→1, 2→3, 4번째 거부, 시작 후 스틸, 검증 실패 불변, 복합 비용, 큐 비용, 소유권 초기화, 루즈볼 유지, 더블 드리블 |
| 3 동시 제출 | 단위 테스트 | 단독 제출 불변, 양측 제출 처리, 중복/낡은 명령 거부, 제출 순서 독립 |
| 4 능력치 | 실행 경로 섭동·표본 실험 | 30개 능력치 실제 변화, 요구된 8개 단조 관계 |
| 5 상태 | 단위·표본 불변식 | 두 선수 동일 스키마, 유한 좌표/속도/자원, 범위 보존 |
| 6 체력 | 단위·실험 | 양측 소비, Endurance 효율, 연속 피로 감쇠 |
| 7 이동/돌파 | 단위·실험 | 공유 이동, 수비 위치/방향/행동이 공간 결과 변경 |
| 8 공격 행동 | 카탈로그·검증 | 10 드리블·풋워크·모든 슛, 선행 조건 및 비용 |
| 9 수비 행동 | 카탈로그·대결 표본 | 17 수비 행동, 경로 차단·컨테스트·회복 의미 |
| 10 충돌 | 동시성/제출 순서·표본 | 같은 틱, 양측 상태/능력치 결합 |
| 11 슛 | 단위·표본 | 성공/실패/블록/파울/리바운드, 거리/각도/체력/속도/수비 |
| 12 시간/큐 | 단위 테스트 | 설정 가능한 틱, 주요 Decision Point, 큐 재평가 및 취소 |
| 13 AI | 단위·자동 경기 | 공개 관측만 참조, 같은 검증, 양역할 진행, 성능 치트 없음 |
| 14 재생 | 명령 재실행 | 초기 설정/시드+명령으로 최종 상태/이벤트 완전 일치 |
| 16 UI | 상위 작업 브라우저 QA | 네 모드, 가림막, 명령/큐/관측, 반응형, 재생 |
| 17 통계 | 자동 10,000 포제션 이상 | 길이/결정점/드리블, 기술 제어/돌파, 턴오버, 슛/스틸/블록/파울, 능력치/조합 승률, 체력, 전체 경기 길이 |

## 실험 원칙

- 같은 시드의 낮은 능력치와 높은 능력치를 짝지어 비교한다.
- 능력치 이름이 행동 메타데이터에 있다는 사실만으로 사용 검증을 통과시키지 않는다.
- 성공률은 실제 시도 수를 분모로 한다. 시도가 없으면 0% 대신 미관측으로 기록한다.
- 포제션 분석과 경기 승률/길이 분석은 분리한다. 포제션 10,000회를 경기 10,000회라고 표현하지 않는다.
- 자동 시뮬레이션은 종료된 포제션을 세며 중단 상한에 도달하면 오류로 보고한다.
- 밸런스 수치가 바뀌면 같은 시드로 수정 전후를 비교한다.
