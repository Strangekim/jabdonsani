## 실험 원칙

- 같은 시드의 낮은 능력치와 높은 능력치를 짝지어 비교한다.
- 능력치 이름이 행동 메타데이터에 있다는 사실만으로 사용 검증을 통과시키지 않는다.
- 성공률은 실제 시도 수를 분모로 한다. 시도가 없으면 0% 대신 미관측으로 기록한다.
- 포제션 분석과 경기 승률/길이 분석은 분리한다. 포제션 10,000회를 경기 10,000회라고 표현하지 않는다.
- 자동 시뮬레이션은 종료된 포제션을 세며 중단 상한에 도달하면 오류로 보고한다.
- 밸런스 수치가 바뀌면 같은 시드로 수정 전후를 비교한다.

## 이벤트 턴 회귀 검증

- `event-turns.test.ts`는 체크볼 → 방향 예측 돌파 → 픽업/루즈볼/탈취 또는 중거리 우위 → 다음 슛/추가 돌파를 실제 제출 경로로 검증한다.
- 방향 예측과 능력치의 영향은 256개 고정 시드로 비교하며 특정 시드의 성공을 보장하지 않는다.
- 우위는 관측과 다음 사건에 전달되며, 추격 수비의 컨테스트·블록 감소와 수비 복귀 모두 실제 계산으로 확인한다.
- 루즈볼은 회수 행동 및 도달 거리가 필요하며 먼 공을 순간적으로 소유할 수 없다.
- 이전 중단 창을 바꾸어도 사건 길이나 추가 사용자 결정이 생기지 않는지 확인한다.
- 횡이동 능력 실험은 비교 능력치가 행동 길이를 바꾸지 않는 명령으로 경과 시간을 고정한다. 행동 종료 후 감속 시간의 차이를 횡이동 성능으로 오인하지 않는다.
- 수비 복귀는 실제 도달 가능한 스프린트 경합에서 검증하며, 늦은 수비가 모든 상황에서 반드시 따라잡는다고 가정하지 않는다.
- 6m 밖의 수비는 예측만으로 돌파를 막거나 순간이동할 수 없다. 후퇴 드리블도 멀리 정지한 수비를 자동으로 끌어오지 않는다.
- 정지 상태의 속도 0, 선택한 속도, 스피드·보호 드리블의 이동 프로필이 실제 도착 위치에 반영되어야 한다.
